A local writing notebook, inspired by Jason Fried.

This update adds **Connect ChatGPT** in The Lab: sign in in your browser and return connected automatically. The OpenAI component is included in every download, with no terminal setup or API key required. It also improves button alignment and mobile controls across the editor, notebook, and Lab.

Sign-in includes cancel, retry, and a link to reopen the OpenAI page. Your ChatGPT plan’s Codex usage limits apply.

Download the ZIP for your computer, **extract the whole folder**, then double-click **Start write_better**. Your browser opens automatically. No Node.js installation or account is needed for writing. Keep the launcher window open while using the app.

| Computer                                       | Download                        |
| ---------------------------------------------- | ------------------------------- |
| Mac with Apple silicon (M1/M2/M3/M4 and newer) | `write-better-darwin-arm64.zip` |
| Mac with an Intel processor                    | `write-better-darwin-x64.zip`   |
| Windows with Intel/AMD processor               | `write-better-win32-x64.zip`    |
| Linux with Intel/AMD processor                 | `write-better-linux-x64.zip`    |

These initial bundles are unsigned; your operating system may ask you to approve the downloaded launcher. See the [installation guide](https://github.com/Bayonle/write-better#install) for details. For optional AI, click **Connect ChatGPT** in The Lab and sign in in your browser. OpenAI’s Codex component is included; no terminal commands or separate installation are needed. Your plan’s Codex allowance applies.

Drafts are saved locally, outside the app folder. Stop the old launcher before opening an updated download. Use **Export notebook backup** to keep an extra copy of your writing.

Source archives below are for developers; most people should choose one of the four bundles above.
